# Vyshnavi — Developer Portfolio

A responsive, accessible dark navy + blue portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and project links
- `style.css` — responsive styles and visual design
- `script.js` — mobile navigation and current footer year

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required. Google Fonts are loaded online; system fallbacks are provided.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `vyshnavi-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; your public URL will appear in Settings → Pages.

## Before publishing
- Replace `YOUR-EMAIL@example.com` with your professional email in `index.html`.
- Replace the generic LinkedIn URL with your actual profile URL.
- Confirm your SLNS repository URL and ensure it is public if you want recruiters to access it.
- Verify the project technologies and descriptions match the implementation. Remove any skills you cannot yet explain.
- CampusGuardian AI is described as a concept / in-progress idea, not a completed application.
- Add your full name preference, professional email, and any other details you want to publish. Do not publish private contact information you do not want public.
